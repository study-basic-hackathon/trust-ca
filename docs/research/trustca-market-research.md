# Trustca 競合調査レポート

高額トレカ売買マーケットプレイス「Trustca」立ち上げに向けた既存サービス調査・ギャップ分析

- 調査日: 2026-08-02
- 対象: magi / スニーカーダンク / メルカリ あんしん鑑定 / PSA
- 位置づけ: Week 1(調査・要件定義)の成果物

---

## 1. 背景

### 1.1 ポケカ市場の急拡大

ポケモンカードは2020年前後を境に「対戦ゲーム」から「キャラクターグッズ+投資商品」へと市場の性質が変化した。主な要因:

- 初代世代(1996年〜)が可処分所得を持つ大人になったノスタルジア需要
- コロナ禍の収集品バブルと、国内外インフルエンサーによる開封・高額購入動画
- PSA等のグレーディングによる「状態の数値化」= 資産化
- リーリエ・マリィ等、イラスト人気による非プレイヤー層の参入
- 品薄・転売・シュリンク剥がし騒動による注目の増幅

### 1.2 真贋問題

高額化に伴い偽造品・リプレイカが激増。高額カード(数万円以上)は「疑ってかかる」のが買い手の前提になっており、真贋の担保がマーケットプレイスの中心的な競争軸になっている。

なお法的には「真贋証明の義務」はないが、偽物を売れば詐欺・商標法違反・債務不履行の責任を負う。中古カードを事業として売買するには古物商許可が必要。

## 2. 既存サービス概要

### 2.1 magi(株式会社ジラフ)

| 項目 | 内容 |
|---|---|
| 形態 | トレカ特化フリマ(ポケカ・遊戯王・ワンピース等) |
| 信頼担保 | 任意オプション「あんしん取引」: 商品が事務局を経由し、真贋鑑定・再シュリンク検査を通過したもののみ買い手へ |
| 鑑定体制 | カードラッシュ、フェイクバスターズ(IVA社)等の外部専門業者と提携 |
| 手数料 | あんしん取引: 商品5万円未満は980円、5万円以上は無料 |
| 売り手審査 | 事前審査はなし。事後認定として「認定出品者マーク」制度あり(下記) |

**認定出品者マーク**: 本人確認書類の認証済み+単価1万円以上の取引50件以上 or 良い評価300件以上+悪い評価が全体の3%未満、が付与条件。条件を満たさなくなった場合や不適切と判断された場合はマーク取消・アカウント利用制限あり。**あくまで取引実績を積んだ後の事後認定であり、入口の審査ゲートではない。**

### 2.2 スニーカーダンク(SODA社)

| 項目 | 内容 |
|---|---|
| 形態 | スニーカー発の鑑定付きマーケットプレイス。トレカにも展開 |
| 信頼担保 | 全品鑑定必須(任意ではなく全取引が鑑定センター経由) |
| 鑑定体制 | 自社鑑定士+X線透過装置(国内唯一)。未開封BOXは内部のパック数・配列まで検査し再シュリンクを排除。シングルはホロ加工・厚み・サイズ・白欠け等をチェック |
| 手数料 | トレカ購入手数料・鑑定料は2025年11月から0円に定常化 |
| 売り手審査 | 事前審査はなし。本人確認制度+違反ペナルティあり(下記) |

**本人確認+ペナルティ**: 本人確認済みアカウントは違反時に利用停止等の対象。空売りには商品金額10%のキャンセル料、繰り返しで永久停止。**抑止は事後的な罰則ベースで、出品開始前の審査はない。**

### 2.3 メルカリ あんしん鑑定

| 項目 | 内容 |
|---|---|
| 形態 | 総合フリマへの後付け鑑定オプション(2024年3月〜) |
| 信頼担保 | 買い手が購入時に有料で選択。商品は鑑定センターを経由(1〜3営業日)、通過で鑑定バッジ付き発送、不合格なら取引キャンセル+全額返金 |
| 手数料 | 鑑定手数料は買い手負担(カテゴリにより変動) |
| 売り手審査 | 実質なし。不合格でも売り手へのペナルティは弱い |

### 2.4 PSA(Professional Sports Authenticator)

| 項目 | 内容 |
|---|---|
| 形態 | マーケットプレイスではなく鑑定・グレーディング専門機関(米国、1991年〜) |
| 内容 | 真贋判定+状態の10段階評価(最高 PSA10 GEM MINT)。密封ケース(スラブ)に封入し固有の証明書番号を発行 |
| 料金・納期 | 1枚数千円〜(申告価値で変動)、数週間〜数ヶ月 |
| API | Public APIで証明書番号照会が可能(`GetByCertNumber`)。公式公開資料に固定quotaの記載はないため、Token発行後にアカウントの利用条件・上限を確認する |
| 競合 | BGS(Beckett)、CGC |

## 3. 弱点分析

### magi
- 鑑定が任意オプション。通常取引は無鑑定の個人間直送で偽物リスクが残る
- 認定出品者マークは取引50件以上等の実績が前提。**高額1点物を初めて売る優良な売り手は認定を得られない**(入口の信頼付与ができない)
- 入口の審査ゲートはなく、悪質出品者の参入自体は防げない

### スニーカーダンク
- 全品鑑定でも鑑定士のヒューマンエラーによるすり抜けは起きる前提(全額返金制度の存在自体がそれを示す)
- トレカの状態基準が曖昧で、買い手・売り手間の認識ズレによるトラブルが発生
- 全品センター経由のため配送が遅く、鑑定無料化はコスト構造として重い
- 本人確認・ペナルティは事後的な罰則ベース。出品開始前の審査はなく、空売り等の問題行動は発生後にしか対処できない

### メルカリ あんしん鑑定
- デフォルトは無鑑定。鑑定は買い手が金を払って選ぶ「保険」
- 鑑定不合格でも取引キャンセルで終わり。偽物出品者へのペナルティが弱く、再出品・再登録が容易

### PSA
- スラブ・ラベル自体の偽造が実際に流通しており「PSA鑑定済み=安全」が崩れ始めている
- 証明書番号は本物でも中身をすり替える手口が存在
- 既存フリマは出品時にPSA番号のAPI照会や現物との突合をしていない

## 4. ギャップ分析: Trustcaの攻め口

既存サービスの信頼担保は全て「商品を毎回検査する」対症療法に寄っている。ここから3つの構造的な穴が導ける。

### 穴1: 「入口で」売り手を審査するサービスが存在しない
magiの認定出品者マーク、スニダンの本人確認+ペナルティはいずれも**事後型**(実績を積んでから認定 / 違反してから罰する)。出品開始前に審査ゲートを設ける**事前型**は空白地帯。具体的に既存サービスがやっていないのは、出品前の審査、古物商許可の確認、保証金。事後型の弱点として、(a) 悪質出品者の参入自体は防げない、(b) 優良でも新規の売り手は信頼を示せない(実績50件の壁)、の2点があり、事前審査はその両方を解決する。

### 穴2: 毎回鑑定はコストと日数の税金
審査済み売り手に信頼スコアを付け、実績に応じて鑑定頻度を下げる設計(与信の発想)なら、安全と速さ・コストを両立できる。

### 穴3: 「PSA鑑定済み」の検証を誰もしていない
スラブ偽造・番号流用が横行しているのに、既存フリマはPSA番号を検証していない。PSA API照会+署名付き電子証明バッジでこの穴を塞げる。

### ポジショニング

> **既存サービスは実績を待つ。Trustcaは入口で審査する。**

| | 商品の検査 | 売り手の信頼担保 | 型 |
|---|---|---|---|
| magi | △ 任意 | △ 認定出品者マーク(実績50件〜) | 事後型 |
| スニダン | ◎ 全品 | △ 本人確認+違反ペナルティ | 事後型 |
| メルカリ | △ 買い手任意 | △ 本人確認のみ | 事後型 |
| **Trustca** | ○ PSA連携+電子証明 | **◎ 出品前審査(eKYC+古物商+保証金)** | **事前型** |

## 5. Trustca 構想メモ

### 売り手審査フロー(候補要素)
- eKYC(TRUSTDOCK、LIQUID等のAPI): 本人確認+顔認証
- 古物商許可番号の提出・確認(事業者)
- 銀行口座の名義一致確認
- 実績・審査制(招待制・紹介制も検討)
- 保証金(デポジット): 偽物発覚時に没収。経済的抑止
- 審査ステート: 申請 → 書類確認 → 審査中 → 承認 / 差戻し / 却下

### 電子証明バッジ
- 鑑定結果(カード名・鑑定日・グレード・個体識別情報)に鑑定者が秘密鍵で署名。W3C Verifiable Credentials 標準が利用可能
- 商品ページのバッジ → 検証ページ(証明書番号照会 or QRで署名検証)
- ブロックチェーンは必須ではない(署名の真正性は公開鍵のみで成立)
- 限界: 署名は「鑑定者の判断」を証明するが、現物との紐付けは封緘ケース・NFC・表面指紋撮影等の物理側の対策が必要

### PSA API連携
- 出品時に証明書番号を入力 → API照会 → カード名・グレードを出品内容と突合 → 「PSA登録情報確認済み」バッジ自動表示
- ハッカソンではAPI Token・利用上限の確認状況に応じて、実データ数件のキャッシュまたはモックAPIも用意する
- 番号流用対策: スラブと売り手を一緒に写した写真提出を審査フローに組み込む

### 法務メモ
- エスクロー構成は資金決済法の論点あり → 収納代行構成 or Stripe Connect等の決済代行で回避が定石
- プラットフォーム自身が買取・販売する場合は自社の古物商許可が必要
- 特定商取引法の表記、真贋保証責任(偽物時の補償設計)を規約で定義
